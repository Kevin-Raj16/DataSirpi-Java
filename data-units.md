# Data Units: Bits to Petabytes

## 1. Bit
- The smallest unit of data in a computer.
- It can have only two values: 0 or 1.
- Example: A switch that is ON (1) or OFF (0).

## 2. Byte
- 1 Byte = 8 Bits
- Used to represent a single character.
- Example: 'A', '1', '@'

## 3. Kilobyte (KB)
- 1 KB = 1024 Bytes
- Used to measure small files.
- Example: A text document.

## 4. Megabyte (MB)
- 1 MB = 1024 KB
- Used for medium-sized files.
- Example: Images, small apps.

## 5. Gigabyte (GB)
- 1 GB = 1024 MB
- Used for larger storage.
- Example: Movies, software applications.

## 6. Terabyte (TB)
- 1 TB = 1024 GB
- Used for very large storage systems.
- Example: Hard drives, servers.

## 7. Petabyte (PB)
- 1 PB = 1024 TB
- Used in large-scale data storage.
- Example: Data centers, cloud storage systems.

- A simple text file → few KB  
- A photo → few MB  
- A movie → few GB  
- Cloud storage → TB or PB
