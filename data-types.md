# Java Data Types (Summary)

## Primitive Data Types

- **byte** → Stores small integer values (-128 to 127).  
  Example: `byte a = 10;`  
  Example: `byte b = -50;`

- **short** → Stores medium integer values.  
  Example: `short a = 2000;`  
  Example: `short b = -1500;`

- **int** → Stores integer values (most commonly used).  
  Example: `int a = 100;`  
  Example: `int b = -5000;`

- **long** → Stores large integer values.  
  Example: `long a = 100000L;`  
  Example: `long b = 999999999L;`

- **float** → Stores decimal numbers (low precision).  
  Example: `float a = 5.5f;`  
  Example: `float b = 3.14f;`

- **double** → Stores decimal numbers (high precision).  
  Example: `double a = 10.99;`  
  Example: `double b = -45.67;`

- **char** → Stores a single character.  
  Example: `char a = 'A';`  
  Example: `char b = '1';`

- **boolean** → Stores true or false values.  
  Example: `boolean a = true;`  
  Example: `boolean b = false;`

---

## Non-Primitive Data Types

- **String** → Stores sequence of characters (text).  
  Example: `String name = "Kevin";`  
  Example: `String city = "Chennai";`

- **Array** → Stores multiple values of same type.  
  Example: `int[] nums = {1, 2, 3};`  
  Example: `String[] names = {"A", "B"};`

- **Class** → Blueprint to create objects.  
  Example: `class Car {}`  
  Example: `Car c = new Car();`

- **Object** → Instance of a class.  
  Example: `Car c = new Car();`  
  Example: `Student s = new Student();`
